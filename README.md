# مؤشر العود — منصة دليل التجار
## Oud Index — Merchant Directory Platform

> منصة الدليل العالمي لتجار العود مبنية على **Next.js 14 + Supabase**
> تكامل مع `oudindex.com` على المسار `/directory/`

---

## ما هذا المشروع؟

هذا مشروع **Next.js كامل** لإطلاق دليل تجار العود تحت مؤشر العود. يشمل:

- صفحة دليل التجار مع بحث وتصفية بـ SSR كامل (محسّن للـ SEO)
- صفحة تاجر فردية مع Schema.org markup (نجوم تظهر في قوقل)
- تسجيل التجار مع تحقق إيميل + جوال
- نظام تقييمات بمستويين (موثّق / غير موثّق)
- لوحة تحكم للتاجر
- لوحة أدمن لمراجعة طلبات التوثيق
- إيميلات تلقائية (تأكيد، إشعار أدمن، ترحيب)
- دعم لغتين: عربي (rtl) + إنجليزي (ltr) مع `hreflang`

- نظام التحقق

## بنية المشروع

```
oud-index-platform/
├── app/                          # صفحات Next.js (App Router)
│   ├── layout.tsx               # القالب الجذري + Header/Footer
│   ├── globals.css              # هوية مؤشر العود البصرية
│   ├── page.tsx                 # الصفحة الرئيسية
│   ├── directory/
│   │   ├── page.tsx             # دليل التجار (مع بحث وتصفية)
│   │   └── [slug]/page.tsx      # صفحة تاجر فردية
│   ├── login/                   # المرحلة 2
│   ├── register/                # المرحلة 2
│   ├── dashboard/               # المرحلة 3 (لوحة التاجر)
│   ├── admin/                   # المرحلة 3 (لوحة الأدمن)
│   └── api/                     # API endpoints (المرحلة 2-3)
│
├── components/
│   ├── Header.tsx               # شريط التنقل العلوي
│   ├── Footer.tsx               # تذييل الصفحة
│   ├── MerchantCard.tsx         # بطاقة تاجر
│   ├── ReviewCard.tsx           # بطاقة تقييم
│   └── StarRating.tsx           # مدخل النجوم التفاعلي
│
├── lib/
│   ├── supabase/
│   │   ├── client.ts            # عميل Supabase للمتصفح
│   │   ├── server.ts            # عميل Supabase للسيرفر
│   │   └── types.ts             # أنواع TypeScript
│   └── utils.ts                 # دوال مساعدة
│
├── supabase/                     # ملفات قاعدة البيانات
│   ├── schema.sql               # هيكل الجداول الكامل
│   ├── policies.sql             # سياسات الأمان (RLS)
│   └── seed.sql                 # ٢٨ تاجر معروف عالمياً للبدء
│
├── package.json
├── next.config.mjs
├── tsconfig.json
├── .env.example                 # انسخيه إلى .env.local
└── README.md (هذا الملف)
```

## التقنيات المستخدمة

| التقنية | الغرض |
|---------|-------|
| Next.js 14 | الإطار الرئيسي (مع App Router و SSR) |
| TypeScript | للأمان والوثوق في الكود |
| Supabase | قاعدة بيانات + مصادقة + تخزين |
| Resend | إرسال الإيميلات (نطاق مخصص) |
| Vercel | الاستضافة (مجاني للبداية) |

## الأوامر السريعة

```bash
# تثبيت المكتبات
npm install

# تشغيل محلياً

# → http://localhost:3000

# بناء للإنتاج
npm run build

# تشغيل النسخة المبنية محلياً للاختبار
npm start
```
